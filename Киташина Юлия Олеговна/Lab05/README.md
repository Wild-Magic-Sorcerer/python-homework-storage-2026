## Задание № 1. Имя и возраст

Имя обязательно. Параметр `--age` принимает целое число от 0 до 120 включительно. С флагом `--greet` строка начинается с обращения.

```console
$ python3 task1.py Анна
Анна
$ python3 task1.py Анна --greet --age 0
Уважаемый(ая) Анна, возраст: 0
```

Чтобы проверить обработку ошибки, выполните `python3 task1.py Анна --age 121`. В сообщении будет текст «Возраст должен быть целым числом от 0 до 120». Команда `echo $?` сразу после этого запуска покажет код завершения `2`.

## Задание № 2. Калькулятор

Скрипт выводит два числа или выполняет над ними заданную операцию. Значения `add`, `sub`, `mul`, `div` означают сложение, вычитание, умножение и деление. Параметр `--precision` задаёт число знаков после запятой, `--output` сохраняет результат в истории. Каждая успешная операция занимает отдельную строку.

```console
$ python3 task2.py 7 2
7.0 2.0
$ work=$(mktemp -d)
$ python3 task2.py 7 2 --operation div --precision 2 --output "$work/history.txt"
3.50
$ python3 task2.py 3 2 --operation mul --precision 0 --output "$work/history.txt"
6
$ cat "$work/history.txt"
3.50
6
```

При запуске `python3 task2.py 7 0 --operation div --output "$work/history.txt"` появится сообщение «Делить на ноль нельзя». В истории останутся две строки.

## Задание № 3. Обработка строк

Параметр `--min-length` задаёт минимальную длину строки, `--unique` оставляет первое вхождение каждой строки. По умолчанию сохраняется исходный порядок. Аргумент `--sort` принимает значения `asc`, `desc` и `none`. Флаг `--count` выводит количество строк, прошедших фильтры.

```console
$ python3 task3.py кот дом кот я --min-length 3 --unique --sort asc
дом
кот
$ python3 task3.py кот дом кот я --min-length 3 --unique --count
2
$ python3 task3.py кот дом --min-length 4 --count
0
```

В первом примере «я» отсеивается по длине, из двух «кот» остаётся один. Запуск `python3 task3.py` выдаст сообщение «Передайте хотя бы одну строку», а `python3 task3.py кот --sort вверх` подскажет допустимые значения.

## Задание № 4. Копирование и замена

Скрипт копирует файл из `--input` в `--output`. Параметр `--replace OLD=NEW` заменяет все вхождения OLD, а `--append-footer` добавляет подпись на отдельной строке. В примере для текстовой замены используется UTF-8. При простом копировании сохраняются все исходные байты.

```console
$ work=$(mktemp -d)
$ printf 'кот и кот' > "$work/in.txt"
$ python3 task4.py --input "$work/in.txt" --output "$work/out.txt" --replace "кот=лиса" --append-footer "Конец"
Количество замен: 2
$ cat "$work/out.txt"
лиса и лиса
Конец
```

Повторный запуск с тем же выходным файлом завершится с сообщением «Файл уже существует. Для перезаписи укажите --overwrite». Чтобы разрешить перезапись, добавьте `--overwrite`. Если входной файл отсутствует, скрипт сообщит его путь.

## Задание № 5. Генератор паролей

Параметр `--length` задаёт длину от 8 до 64 включительно, `--count` задаёт количество паролей. По умолчанию генерируется один пароль. Флаги `--no-digits` и `--no-special` исключают цифры и специальные символы соответственно. При обоих флагах в алфавите остаются латинские буквы. В коде отдельно проверяется случай пустого алфавита.

```console
$ work=$(mktemp -d)
$ python3 task5.py --length 8 --count 2 --no-digits --no-special --output "$work/demo.txt"
$ awk '{print length($0)}' "$work/demo.txt"
8
8
```

Скрипт записал по одному случайному паролю в строку. Команда `awk` показывает длину каждой строки. Если опустить `--output`, пароли будут выведены в терминал. Запуск `python3 task5.py --length 7` выведет ошибку «Длина пароля должна быть от 8 до 64».
