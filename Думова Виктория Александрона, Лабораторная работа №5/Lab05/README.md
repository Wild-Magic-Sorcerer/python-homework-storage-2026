### Задание №1
Напишите скрипт, который принимает обязательный позиционный аргумент — имя пользователя. Добавьте необязательный аргумент аргумента и флаг приветствия. Если указан возраст, вы вводите его вместе с именем. При выборе флага приветствия следует произносить слова «Уважаемый(ая)». Убедитесь, что возраст является целым числом от 0 до 120. При некорректном возрасте скрипт должен вывести понятное сообщение об Нуждах и пройти с кодом 2.
### Задание №2
Создайте программу, которая принимает два позиционных аргумента — числа x и y. Добавьте необязательный аргумент операции со значениями add, sub, mul или div. Если операция не указана, программа должна просто вывести оба числа. Добавьте аргумент точности, который задаёт количество знаков после запятой в результате. Добавьте название аргумента файла для сохранения результата выполненной операции. Программа должна правильно обработать разделение на ноль и не перезаписывать предыдущую историю.
### Задание №3
Реализовать скрипт, который принимает один или несколько строковых аргументов. Добавьте флаг подсчёта количества строк, флаг для вывода только случайных строк и аргумент для вывода строк, длина которых не меньше указанных значений. Добавьте --sortсо значениями аргументами asc, descили none. По умолчанию следует сделать вывод построчно. Если указан флаг подсчета количества строк, вы вводите только количество строк ПОСЛЕ применения фильтров. При пустом списке аргументов или неизвестном объяснении --sortвы делаете понятное сообщение для неуважаемого пользователя об ошибках.
### Задание №4
создать утилиту, которая принимает аргументы --inputи --output. Утилита должна скопировать критерий входного файла в выходной файл. Добавьте необязательный аргумент --replaceв формулировку OLD=NEW, который заменяет все вхождения строк OLDв текст NEW. Добавьте необязательный аргумент --append-footer, который добавляет указанный текст в конец выходного файла. добавьте флаг, который разрешает перезапись существующего выходного файла. Программа должна проверять состояние входного файла, не перезаписывать выходной файл без флага перезаписи и выводить количество выполненных замен.
### Задание №5
Создать скрипт для генерации паролей. Он должен принять аргумент длины и аргумент количества паролей для генерации. Добавьте флажки (2 шт.), которые записывают цифры или специальные символы из пароля. Добавьте аргумент для сохранения сгенерированных паролей в файле. Программа должна включать пары (по последовательному алгоритму), проверять, что длина пароля находится в интервале от 8 до 64, и выводить ошибку, если после исключения символов генерация пароля невозможна.
